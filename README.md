## Описание мода / Description
Высокотехнологичный тактический звуковой пак для Circuit 04. Полностью обновляет аудиосистему: голографические клики интерфейса, шаги экзоскелета с микро-сервоприводами, плазменные выстрелы порталгана, герметичные пневмошлюзы и дарк-синтвейв радио.

## Установка мода / Installation

### Способ 1: Автоматическая установка через игру
1. Запустите **Circuit 04**.
2. Откройте Главное меню -> **«Моды»** -> вкладка **«Репозиторий»**.
3. Найдите мод **CyberTac: Tactical Sci-Fi SFX** и нажмите кнопку **«Установить»**.

### Способ 2: Ручная установка из ZIP
1. Скачайте архив `cybertac_sfx.zip` из последнего [Релиза](https://github.com/game-mods-repo/circuit04-mod-cybertac_sfx/releases/latest).
2. Поместите архив или распакованную папку в директорию `mods/` (или `mods/maps/` для карт).
3. В игре во вкладке «Менеджер модов» нажмите кнопку **«Обновить список»**.
